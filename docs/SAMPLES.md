# 样例问题清单

`sample_data/dirty/` 里的每一类问题都能在页面上找到证据行。

| 问题 | 位置 | 期望 |
|---|---|---|
| UTF-8 BOM | 触点文件首行 | 首列名不带 `\ufeff` |
| GB18030 中文表头 | 别名文件 | 回退解码成功，编码记为 gb18030 |
| CRLF 与 LF 混用 | 触点文件第 3、7 行 | 逻辑行数 = 记录数 |
| 重复表头 | 触点文件第 16 行 | 单独计数，不当数据行 |
| 空行 | 触点文件第 15 行 | 单独计数 |
| 列数多一列 | `TP-1026` | `TD_COL_COUNT` |
| 末行截断 | 文件最后一行 | 文件状态 truncated，半行隔离 |
| 千分位 | `TP-1008` | 1,234.50 元 → 123450 分 |
| 全角数字 | `TP-1027` | 180.00 元 → 18000 分 |
| 万元单位 | 订单 `O-1002` | 0.86 万 → 8600 元 |
| 空值哨兵 | 订单 `O-1005` | `OD_GMV_INVALID` |
| 重复订单号 | `O-1007` 两行 | `OD_DUP_CONFLICT` |
| 时区混写 | `TP-1007` / `TP-1008` | 同一时刻，同窗口 |
| 迟到入库 | `TP-1005` | 计入且 `late=1` |
| 窗口左端 | `TP-1003` | 计入 |
| 下单同一时刻 | `TP-1004` | 不计入 |
| 重复触点编号 | `TP-0016` 两行 | 两条都隔离 |
| 空渠道 | `TP-1021` | `TD_CHANNEL_UNKNOWN` |
| 未知渠道 | `TP-1022` | `TD_CHANNEL_UNKNOWN` |
| 负成本 | `TP-1025` | `TD_COST_INVALID` |
| 别名环与自引用 | 别名文件 | 合并为一个等价类 |
| 别名坏行 | 别名文件最后一行 | `ALIAS_BAD_ROW` |
